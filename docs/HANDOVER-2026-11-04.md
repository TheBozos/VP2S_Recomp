## How-tos learned today

- **Ground truth**: PCSX2 GS dump (Shift+F8) + `scratchpad/t2/chain.py` (`GSDUMP=<file>`: post passes grouped by
  FRAME/TEX0/ALPHA/RGBA), `t2/fogstat.py` (FGE/F per target), `t2/veil2.py <S> <lo> <hi>` (vertices with ST/Q/F).
  `scratchpad/pcsx2_gsdump.ps1 -State N` loads a save state and takes F8 + Shift+F8. Walking needs the **left
  stick (W/A/S/D)**, not the arrows; key holds through keybd_event did not move Alicia reliably.
- **Which mesh is that?** Temporary colour-by-mesh mode (each mesh flat, hashed colour, log `name -> colour`), then
  read the pixel; compare in the **same run** - capture timing differs between runs, pixel matching across runs misled
  twice today. Hiding a mesh (`part+offset`) to confirm.
- Converted (disc) materials can differ from the **live EE block**: FGE bits, and the object colour row. Check the live
  data before trusting the converted mesh.
- The original draw FUN_0023A950: microcode index from +0x517/model +0x57/object +0x66/model +0x3F; masks +0x7A4
  (hide), +0x7A6 (colour override +0x7E0..), +0x7A8 (callback +0xF8 chains a sub-packet). None were set in Logun.
- Native capture: `PS2X_NATIVE_CAPTURE_DIR` + `PS2X_NATIVE_CAPTURE_INTERVAL`; test runs via
  `RUNSCRIPT=logun_usa.sh bash guardrun.sh <tag> ENV=...` in the scratchpad.

  capture runs; no meaningful FPS gain is claimed. The overlay now counts native
